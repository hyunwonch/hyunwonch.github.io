COCHON is a configurable heterogeneous baseband SoC for high-speed optical communication networks. It integrates a large receive-baseband processing region with multiple forward-error-correction engines, transmit and receive baseband processors, sample and bit buffers, phase-locked loops, and an embedded host system. By combining programmable baseband processing with specialized coding hardware, the SoC is designed to support demanding optical links while retaining flexibility across communication modes and processing requirements.
