RF-system design traditionally forces a difficult choice between power efficiency and software programmability. This work presents a hardware-software framework intended to deliver both, opening the door to systems that use constrained resources more effectively. DASH demonstrates this approach through RF convergence, in which common spectrum and waveforms support several distributed functions and objectives at the same time. The framework combines a software environment with a coarse-scale heterogeneous system-on-chip design.
