# Google TPU Technical Review (Version-by-Version)

This folder contains a highly technical, version-separated review of Google TPU generations from v1 through v6e (Trillium).

## Files
- `01_TPU_v1.md`
- `02_TPU_v2.md`
- `03_TPU_v3.md`
- `04_TPU_v4.md`
- `05_TPU_v5e.md`
- `06_TPU_v5p.md`
- `07_TPU_v6e_Trillium.md`

## Scope
- Architecture and microarchitecture shifts
- Memory system evolution
- Interconnect and pod topology scaling
- Compiler/runtime implications
- Workload fit (training vs inference)
- Bottleneck analysis by generation

## Sources used repeatedly
- Google Cloud TPU docs (v2/v3/v4/v5e/v5p/v6e)
- Google Cloud blog post on first TPU (v1)
- ISCA / arXiv TPU papers (v1 analysis, v2/v3 pod analysis, v4 supercomputer paper)
